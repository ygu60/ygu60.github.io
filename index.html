01 Selected Projects

Data Engineering · Statistics · ML

Quant Alpha Research Pipeline

A research and backtesting pipeline in Python for statistical trading strategies, using 10 years of real market data (2016–2026, 23 names). It pulls and caches data from Yahoo Finance and cleans up delistings and ticker reassignments. From there it runs vectorized backtests with look-ahead protection and transaction costs, then applies walk-forward, out-of-sample validation.

  • Best strategy: short-term reversal with volatility targeting and a regime gate. It reached an out-of-sample Sharpe of 0.44 (PSR 0.91, max drawdown −16.8%). I cross-checked it against an independent Markov-switching model.
  • Rejected an overfit variant that flipped from strongly positive to strongly negative when the lookback window changed.
  • Tested ML models (Ridge, Random Forest, Gradient Boosting, and a PyTorch MLP) using purged walk-forward CV and a shuffled-label permutation test as a negative control. None of them beat the noise floor, and I documented them as honest negative results.
  • Includes unit tests for the backtest engine, the risk overlay, and feature causality, plus a written research memo.

Python · pandas · NumPy · scikit-learn · PyTorch · statsmodels · matplotlib

Instrumentation · Data Pipeline · Signal Processing

ODMR Automated Acquisition & Analysis Pipeline

An end-to-end pipeline for an optically detected magnetic resonance experiment on NV centers. It talks directly to lab hardware (a Keysight oscilloscope and function generator) over PyVISA/SCPI and captures thousands of triggered sweeps. Then it filters, despikes, calibrates, and averages the signal to produce clean spectra.

  • Collected ~10,000 real sweeps across 10 magnetic-field conditions, and wrote a standalone diagnostic tool to debug trigger problems without risking a run.
  • Built an adaptive N-Lorentzian fit that detects peaks automatically. It replaced two fixed-model fits that failed, and I documented why each one failed.
  • Produced reproducible figures (small multiples, ridgelines, 3D terrain), a full uncertainty analysis, and a LaTeX paper.

Python · PyVISA · SciPy · NumPy · matplotlib · LaTeX

Machine Learning · Computer Vision · Research

Neuroaesthetics: Predicting Aesthetic Ratings of Mosaic Art

An undergraduate research project at WashU (Jan–Aug 2025) that modeled how people perceive mosaic art computationally. I built the dataset, engineered features, and ran the statistical modeling.

  • Built a dataset of 982 images with multi-level statistical and segmentation features.
  • Used LASSO regression, entropy measures, and spectral analysis to find which features predict aesthetic ratings.
  • Compared segmentation methods (SAM2 and kernel graph cuts) for extracting features at the tile level and at 60+ semantic levels.
  • Presented an abstract at the Spring 2026 Undergraduate Research Symposium.

Python · MATLAB · SAM2 · scikit-learn · image processing
