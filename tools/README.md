# tools/

`build_pdf.py` builds the print portfolio, `assets/Jimmy_Gu_Portfolio.pdf`. It has 5 US Letter pages: a cover with a
visual index, then one page per project. `print.html` is generated by the script. Don't edit it by hand. It carries a
`noindex` tag so search engines don't list this duplicate of the site.

## Rebuild

From WSL, run the script with a **Windows** Python, because it drives Windows Chrome:

```bash
/mnt/c/Users/Owner/AppData/Local/Temp/jg_venv/Scripts/python.exe "$(wslpath -w ~/portfolio/tools/build_pdf.py)"
```

Requirements:

- Google Chrome at `C:\Program Files\Google\Chrome\Application\chrome.exe` (use `--chrome` to override).
- A network connection. The script downloads static copies of the Google web fonts, so the PDF embeds real fonts
  instead of Type 3 outlines.
- Python 3 with Pillow and PyMuPDF. Without PyMuPDF the PDF still builds, but you lose the page-count check, the
  metadata/bookmarks and the previews. If the temp venv above is gone, recreate it:
  `py -m venv jg_venv` and then `jg_venv\Scripts\pip install pillow pymupdf`.

Options:

| flag | what it does |
| --- | --- |
| `--preview DIR` | also renders each PDF page to `DIR/pageN.png` so you can look at it (use a Windows path) |
| `--html-only` | only rewrites `tools/print.html` (open it in a browser for a quick preview) |
| `--max-img-px N` | downscales the print copies of the images to at most N px, if the PDF gets too big |
| `--keep-temp` | keeps the Windows temp dir used for staging |

The build finishes with `OK`. It stops with an error if any of these fail:

- The layout check: nothing may extend past a page's margins, no text box may be clipped, and every image and
  font must load.
- The PDF must have exactly 5 pages.
- The PDF must be under 5 MB.

The script also prints each page's spare height and its visual share (the fraction of the page taken by images, and
by figures including their captions).

## Where the content comes from

- **Web pages.** Titles, outcomes, KPI tiles, "What I did" bullets, skill tags, constraints, figure images, and
  annotation-pin positions are read from `index.html` and `projects/*.html`. Edit a page and rebuild, and the PDF
  follows.
- **The `PRINT` dict in `build_pdf.py`.** This holds the print-only choices:
  - which figures each page shows, and their size (`rows`, `h`)
  - image crops
  - shorter captions and pin notes
  - condensed bullets (`did`)
  - the cover one-liners
  - the objective and the "Against the objective" scorecard
  - the one-line "What I learned" strip (its bold lead must match the page's lesson box)

  Every condensed text there must restate what the web page says. Don't add new facts in `PRINT`.

If a page overflows after an edit, the layout check names the page. Fix it by lowering that page's first-row `h`
(the hero figure's height) or by shortening its captions.
